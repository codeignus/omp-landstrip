# omp-landstrip

Sandboxed bash tool for omp (Oh My Pi): OS-level filesystem and network
confinement for model-driven shell execution, powered by the
[landstrip](https://github.com/landstrip/landstrip) sandbox.

Status: early development — this package is being transformed from its
pi-landstrip origin into a native omp extension. Subagents, commands, and
the dashboard pane are not part of the initial surface.
